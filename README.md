# Layout Designer · React + Konva v2.0

空间布局设计器(装箱规划 / 房间设计 / 工位设计)的 React 版。

## 这一版有什么(功能完整版)

已从单文件 HTML V1.6 迁移并模块化:

### 三大组件模块(左侧库)
- 🪑 **家具模块**:桌子、椅子、沙发、柜子、床、圆桌
- 🚪 **门窗模块**:门、双开门、窗、飘窗、墙体
- 📦 **箱货模块**:托盘1210/1111、货架、纸箱大中小
- 🖥️ **桌面物件**:电脑、显示器、键盘、设备
- ➕ 自定义矩形

### 核心系统
- **区域系统**:40HQ/20GP集装箱、房间、工作台、自定义,真实 mm 尺寸,自动缩放居中
- **图层系统**:L0地面/L1台面/L2顶层 —— 桌上放电脑、托盘上放箱子不算碰撞
- **碰撞检测**:仅同层重叠报红框
- **网格 + 吸附**:50/100/500/1000mm 可选
- **属性面板**:名称/图层/长宽高/位置/旋转/颜色,全联动
- **统计面板**:面积、分层占用、地面利用率、碰撞数
- **JSON 存取**:保存/加载布局
- **快捷键**:R旋转 / Del删除 / Ctrl+D复制 / 方向键移动

## 环境要求

- Node.js >= 18(建议 20+)
- npm >= 9

## 运行步骤

```bash
# 1. 进入项目目录
cd layout-designer

# 2. 安装依赖(第一次会下载 react/konva 等,需联网)
npm install

# 3. 启动开发服务器(会自动打开浏览器 http://localhost:5173)
npm run dev
```

如果浏览器没自动打开,手动访问终端里显示的地址(通常是 http://localhost:5173)。

## 你应该看到什么

- **顶部工具栏**:场景选择、区域尺寸、网格、吸附/碰撞开关、旋转/复制/删除、JSON存取
- **左侧组件库**:家具/门窗/箱货/桌面 四大模块
- **中间画布**:白色区域框 + 网格,居中自适应
- **右侧面板**:属性 + 统计

## 交互测试清单

- [ ] 切换场景(如 40HQ集装箱 → 房间)→ 区域尺寸变化并重新居中
- [ ] 从「家具模块」点桌子 → 画布出现桌子,带尺寸标签和 [L0]
- [ ] 从「箱货模块」点托盘,再点纸箱 → 纸箱是 L1
- [ ] 把纸箱(L1)拖到托盘(L0)上 → **不报碰撞**
- [ ] 把两个桌子(L0)重叠 → **报红框碰撞**,统计显示碰撞数
- [ ] 拖动物体 → 若开吸附,自动对齐网格
- [ ] 选中物体 → 右侧属性面板可改长宽高/位置/旋转/颜色,画布实时更新
- [ ] R 旋转 / Del 删除 / Ctrl+D 复制 / 方向键移动
- [ ] 保存 JSON → 清空 → 加载 JSON → 布局恢复
